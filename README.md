## ▶️ Quick start
1. Clone the repo:
   git clone https://github.com/Jeevaprakash-T/Gen_AI_jeevaprakash_june-26_training.git
2. (Optional) Create and activate a virtual environment:
   python -m venv .venv
   source .venv/bin/activate  # macOS/Linux
   .venv\Scripts\activate     # Windows
3. Install dependencies (if a requirements.txt exists):
   pip install -r requirements.txt
4. Launch Jupyter:
   jupyter notebook
5. Or open any notebook in Colab:
   https://colab.research.google.com/github/Jeevaprakash-T/Gen_AI_jeevaprakash_june-26_training/blob/main/<NOTEBOOK>.ipynb
